🛒 Lista de Compras

Este projeto é um aplicativo de lista de compras desenvolvido com React Native, Expo e TypeScript. Ele permite adicionar produtos, definir quantidades e remover itens, facilitando a organização das compras.

✨ Funcionalidades
Adicionar produtos e suas respectivas quantidades.
Remover produtos da lista.
Validar o nome dos produtos antes de adicioná-los.
Definir a quantidade como 1 quando o campo estiver vazio.
Exibir uma mensagem quando a lista estiver vazia.
Acompanhar a quantidade de itens cadastrados.
🛠️ Tecnologias utilizadas
React Native
Expo
TypeScript
React Hooks (useState)
💻 Como baixar e executar o projeto
1. Baixar o projeto
Acesse este repositório no GitHub.
Clique no botão verde Code.
Selecione Download ZIP.
Após o download, extraia o arquivo ZIP para uma pasta do computador.
2. Preparar o ambiente

Antes de executar o projeto, é necessário ter instalado:

Node.js: https://nodejs.org/
Visual Studio Code: https://code.visualstudio.com/
3. Abrir o projeto

Abra a pasta do projeto no Visual Studio Code.

No terminal integrado, entre na pasta que contém o arquivo package.json, caso ainda não esteja nela.

4. Instalar as dependências

Execute o comando abaixo no terminal:

npm install

Esse comando instala as bibliotecas necessárias para o funcionamento do aplicativo.

5. Executar o aplicativo

Após a instalação, execute:

npm start

O Expo será iniciado e apresentará as opções para abrir o aplicativo.

Celular: escaneie o QR Code com o Expo Go.
Navegador: pressione w no terminal do Expo para abrir a versão web, se compatível com a configuração do projeto.
📁 Organização dos arquivos
App.tsx: componente principal e gerenciamento dos itens.
index.tsx: ponto de entrada do aplicativo.
types.ts: definição da estrutura dos itens de compra.
components/Cabecalho.tsx: cabeçalho do aplicativo.
components/FormularioItem.tsx: formulário para adicionar produtos.
components/ItemCompra.tsx: componente visual de cada produto.
components/ListaCompras.tsx: exibição da lista de produtos.
